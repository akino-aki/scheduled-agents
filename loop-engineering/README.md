# loop-engineering

ループエンジニアリング — **AIを自律ループで回して成果物を作らせる設計手法**に絞った情報収集。
**毎日 7:40 (JST)** にクラウドエージェントが収集する。

分野が狭いため新しい情報が無い日もある。その日は「該当なし」とだけ書かれる（件数を埋めない）。

## 追っている観点

- 概念・提唱（Addy Osmani、Ralph Loop、Anthropic 公式の解説）
- **停止条件・完了条件の設計** — どうやってループを止めるか、暴走をどう防ぐか、最大反復回数
- 実装（`/loop` などの仕組み、ハートビート、ワークツリー並列、サブエージェント分業、状態管理）
- **実践記録** — 何回ループして何が起きたか、失敗談、コスト実測。ここを最も重視する

最後の「実践記録」を重視しているのは、この分野が提唱と実測の乖離が大きく、
概念の解説だけでは実際に回したときに何が起きるか分からないため。
