- **[実践][実装] バックグラウンドBashが実際には終了しているのに5〜7時間「Running」表示のまま残る不具合と、`run_in_background`でリモートシェルを叩くとstdinが開いたままでEOFを待ち続け最大約10時間ハングする不具合が同じセッションで発生——原因は別々の2系統と特定** — https://github.com/anthropics/claude-code/issues/94059
  - **何が起きたか**: フォアグラウンドのBash呼び出しが600秒タイムアウトでバックグラウンドへ移された後、実プロセスは`ps`上に存在しないのに「Running」表示だけが5時間27分〜7時間40分残り続けた(`TaskStop`自体は成功する)。別に、`ssh HOST 'md5sum …'`のようなリモートシェルコマンドを`run_in_background:true`で実行すると、子プロセスがEOFを待ってstdinを開いたままハングし続け、あるケースでは9時間56分後まで気づかれなかった(ssh側のプロセスをkillすると正常完了した)。14時間のセッションで536件のタスクが完了する中での発生。(2026-09-13報告、Claude Code Desktop 2.1.240・macOS、Issue open)
