- **[公式][実務][企画] `ant` CLI v1.30.0（9/3）— `ant apply`追加、エージェント・Skill・スケジュールデプロイメントをリポジトリのファイルから宣言的に作成・更新可能に** — https://platform.claude.com/docs/en/cli-sdks-libraries/cli/apply
  - **何が起きたか**: Claude Managed Agents向けCLI「ant」のv1.30.0で`ant apply`が追加された。エージェント・環境・Skill・メモリストア・cron指定できるスケジュールデプロイメントをMarkdown/YAML/JSONのファイルとしてリポジトリに置き、`ant apply`で作成・更新できる。実行結果は`claude-lock.json`に記録され、これをコミットしておけば次回以降は同じリソースを更新でき、CIからの`ant apply --yes`実行にも対応する。
  - **なぜ注目されているか**: これまでClaude Managed Agentsのエージェントや定期実行デプロイメントは、APIを直接叩くかConsoleで作る運用が中心で、Terraformのように「コードとしてレビュー・バージョン管理する」手段が公式には無かった。今回、宣言→plan表示→承認→適用というIaC的なワークフローが`ant apply`として整理された形になる。
  - **使いどころ**: このダイジェストのように「毎朝cronでエージェントを起動しGitHubにpushする」運用を、`deployments/*.md`のfrontmatterでスケジュールごと宣言的に管理し直せる可能性がある。個人開発の自動化ネタとしてYouTube収録の題材にもしやすい。CDK/ECSの日常レビューには直接関係しないので今すぐ導入する必要はない。

- **[公式][実務] Claude Code v2.1.260（9/3）— `/ultrareview`のクラウドレビュー待機タイムアウトを30分→45分に延長** — https://github.com/anthropics/claude-code/releases/tag/v2.1.260
  - **何が起きたか**: v2.1.260で、`/ultrareview`（`claude ultrareview`）がクラウド側の長時間レビューを待つタイムアウトが30分から45分に延長された。
  - **なぜ注目されているか**: 4月報告のissue #54229では、diffが6,608行・23ファイル・6.6MBというさほど極端ではない規模のPRで、サンドボックスの起動やリポジトリのクローンは成功するのにその後29分間イベントが一切流れず30分でタイムアウトする不具合が、同一PRで2回とも再現する決定論的な問題として報告されていた（無料実行枠を消費して成果ゼロという実害付き）。今回の延長はこの種の「巨大ではないのに詰まる」ケースへの当面の緩和策で、根本原因とみられるイベントストリームの無応答自体が直ったとは明言されていない。
  - **使いどころ**: CDK/ECSのマルチアカウント構成のように複数ファイルにまたがる大きめのPRで`/ultrareview`を使っているなら、これまでタイムアウトで無駄になっていたレビューが完走しやすくなる。ただし対症療法である点は踏まえ、詰まる場合は無料実行枠の消費状況も併せて確認しておくとよい。

- **[公式][実務][企画] Claude Code v2.1.260（9/3）— `/advisor`がheadless（`-p`/Agent SDK）セッションやRemote Control・Desktopでもテキストコマンドとして設定可能に** — https://code.claude.com/docs/en/advisor
  - **何が起きたか**: v2.1.260で、`/advisor`（メインモデルが判断に詰まった時だけ会話全体をより強いモデルに見せて助言を仰ぐ機能）を、Desktopアプリ・Remote Control・`-p`やAgent SDKのheadlessセッションからも`/advisor opus`のようなテキストコマンドで設定できるようになった。
  - **なぜ注目されているか**: advisor機能自体は以前から存在するが、モデルの設定はインタラクティブなセッションでのメニュー選択か、起動時の`--advisor`フラグ・`advisorModel`設定への依存が前提だった。人が画面を見ていないheadless実行の途中でモデルを動的に変更・オフにする手段が今回のバージョンで揃った形になる。
  - **使いどころ**: このダイジェストのようなスケジュール実行のroutineや自作`/loop`で、「普段は安いモデルで回すが、判断に迷った場面だけ強いモデルに意見を聞く」構成をheadless実行のまま組める可能性がある。ただしAnthropic API限定の機能でBedrock等では使えない点に注意（社内のマルチアカウント環境がBedrock経由なら対象外）。
