- **[公式][実務][企画] Claude Code v2.1.229 — Workflowのファンアウトでプロンプトキャッシュを効かせる段階起動に** — https://github.com/anthropics/claude-code/releases/tag/v2.1.229
  - **何が起きたか**: 8/12リリースのv2.1.229で、`Workflow`ツールの`parallel`/`pipeline`によるファンアウト時、同じプロンプトプレフィックスを持つ兄弟サブエージェントの起動をわずかに段階化し、後続エージェントが先行エージェントのキャッシュ済みプレフィックスを読めるようにする最適化が入った。`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0`で無効化可能。
  - **なぜ注目されているか**: これまで同一プレフィックスの兄弟エージェントを完全同時に起動すると、キャッシュ書き込みが完了する前に他のエージェントが同じプレフィックスを読みに行き、プロンプトキャッシュのヒットを取りこぼしていた。今回の変更でその無駄が減る。
  - **使いどころ**: `/loop`やWorkflowスクリプトで同じ指示文をベースに大量のサブエージェントをファンアウトさせている場合、設定変更なしでトークンコストがわずかに下がる。効果を確認したいなら`ANTHROPIC_LOG=debug`等でキャッシュヒット率を見比べるとよい。

- **[公式][実務] Claude Code v2.1.229 — `/install-github-app` 生成のPRレビューワークフローが「実行完了するがレビューを投稿しない」不具合を修正** — https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
  - **何が起きたか**: 8/12リリースのv2.1.229で、`/install-github-app`が生成するClaude Code Reviewワークフローが、GitHub Actions上で正常終了するにもかかわらずPRにレビューを投稿しないまま完了する不具合が修正された。
  - **なぜ注目されているか**: GitHub上のissueを追うと、GitHub Actions経由のPRレビュー自動化では「チェックは成功するがレビューコメントが出ない」「0件レポートで終わる」といった無言の失敗が2月頃から複数報告され続けていた系統の不具合。今回はそのうち`/install-github-app`生成ワークフロー固有の原因が直った。
  - **使いどころ**: `/install-github-app`でPRレビューを自動化していて「動いているはずなのにレビューが付かない」状態に心当たりがあるなら、v2.1.229へのアップデートで直る可能性がある。経験の浅いメンバーのレビュー品質を揃える目的でこの自動化を使っているなら、更新後に一度動作確認しておくとよい。
