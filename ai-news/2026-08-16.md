- **[公式][実務][企画] Claude Code v2.1.233 — Sonnet 5などの新モデルでTodo/Taskツールがデフォルト無効に** — https://code.claude.com/docs/en/tools-reference
  - **何が起きたか**: 8/14リリースのv2.1.233から、Opus 4.8・Sonnet 5・Fable 5・Mythos 5以降のモデルでは`TodoWrite`および`TaskCreate`/`TaskGet`/`TaskUpdate`/`TaskList`がデフォルトで提供されなくなった。有効化するには`CLAUDE_CODE_ENABLE_TODO_TOOLS=1`を設定する必要がある。ただしバックグラウンドセッションと Claude Code on the web では、モデルによらず引き続き全ツールが提供される。
  - **なぜ注目されているか**: 公式の説明では、新しいモデルは書き出したチェックリストなしでも複数ステップの作業を追跡できるため、ツール定義とリマインダーがコンテキストを消費するだけになったとして外された。作業中に画面上のタスクリスト表示が消えたと感じたら、この仕様変更が原因。
  - **使いどころ**: 対話セッションでタスク進捗が見えなくなって困るなら`CLAUDE_CODE_ENABLE_TODO_TOOLS=1`を明示すればよい。`/loop`やWorkflowで動かす自作skillがタスクリストを前提にしている場合は要確認だが、Workflow経由のバックグラウンド実行なら今回の変更の影響を受けない。

- **[公式][実務] Claude Code v2.1.233 — Bashツールにcgroupメモリ上限を追加、暴走プロセスでのセッション停止を防止** — https://github.com/anthropics/claude-code/releases/tag/v2.1.233
  - **何が起きたか**: 同v2.1.233（Linux限定・オプトイン）で、Bashツールが実行するコマンドに対しcgroupベースのメモリ上限を`CLAUDE_CODE_TOOL_MEMORY_LIMIT`環境変数で設定できるようになった。暴走したビルド等のプロセスがシステム全体を巻き込まず、そのプロセスだけがOOM Killされるようになる。
  - **なぜ注目されているか**: サブエージェントが大量のBashラッパープロセスを生成し続けメモリ・CPUを食い潰す事例はこれまでも報告があり、4月報告のissue #50191では、サブエージェント経由のbashラッパーが数分でload average 600超まで増え、tmuxごとOOM Killされてホストのハードリセットが必要になったケースが記録されている（Anthropic側はClosed as not plannedのまま）。
  - **使いどころ**: CDK/ECSのビルドやテストをClaude Codeに長時間任せていて、稀に環境ごと固まった経験があるなら試す価値がある。Linux上のリモート実行環境（EC2やセルフホストランナーなど）で`CLAUDE_CODE_TOOL_MEMORY_LIMIT`を設定しておくと、暴走時もセッション自体は継続できる可能性が高い。

- **[公式] Claude Code v2.1.233 — `--worktree`と`claude agents`ビューがGitLabのマージリクエストに対応** — https://github.com/anthropics/claude-code/releases/tag/v2.1.233
  - **何が起きたか**: 同v2.1.233で、`--worktree`フラグと`claude agents`ビューがGitLabのマージリクエストURLを受け付けるようになり、MRは`!N`表記で表示される。前日のv2.1.232でもプラグインマーケットプレイスがGitLabの素のリポジトリURLに対応し、GitLabトークン系のシークレット秘匿化も追加されていた。
  - **なぜ注目されているか**: この週はGitLab対応が「プラグインマーケットプレイス→シークレット秘匿化→MR/worktree対応」と立て続けに拡張されており、これまでGitHub前提だった機能をGitLabにも横展開する動きが1週間の間に集中していた。
  - **使いどころ**: 今の開発はGitHub中心のため今すぐ使う場面はない。社内の別チームやOSS貢献先がGitLabを使うようになったら、`claude --worktree <MR URL>`でそのままレビュー用worktreeを作れる、と覚えておく程度でよい。
