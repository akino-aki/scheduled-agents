- **[公式][実務] Claude Code v2.1.239 — フルスクリーン描画のデフォルト提供が、Bedrock/Vertex/Foundry経由のセットアップにも拡大** — https://github.com/anthropics/claude-code/releases/tag/v2.1.239
  - **何が起きたか**: 8/21リリースのv2.1.239で、ちらつき除去・メモリ使用量一定化・マウス操作対応を狙うフルスクリーン描画（`/tui fullscreen`）のデフォルト化条件が拡大した。公式ドキュメントによれば、「このマシンで最初にClaude Codeを起動したバージョンがv2.1.239以降」であれば、Bedrock・Google CloudのAgent Platform・Microsoft Foundry経由のセットアップでも新規セッションはフルスクリーンで起動するようになった。
  - **なぜ注目されているか**: フルスクリーン描画はこれまで「Anthropicへfeature flagを問い合わせられるセッションで、かつ5/6以降に初回起動」という条件でしかデフォルト化が進んでいなかった。Bedrock/Vertex/Foundry経由のセッションはそもそもfeature flagを取得しない仕組みのため、この条件だけでは永久に対象外のままだった。今回はバージョン番号ベースの判定を別途追加することで、その抜け穴を埋めた形になる。
  - **使いどころ**: 社内プロキシ経由でBedrockを使う構成で新しいマシンにClaude Codeをセットアップするなら、今後はフルスクリーンUIが既定になる。8/22付ダイジェストで既報のv2.1.239「フルスクリーン中のフォーカス復帰クリックが権限プロンプトへの誤回答になる」不具合修正とセットで踏まえておくとよい。既存マシンで長時間セッションのメモリ肥大や画面のちらつきに悩んでいたなら、`/tui fullscreen`で手動有効化を試す価値がある。

- **[公式] Claude Code v2.1.239 — `/claude-api upgrade` を追加、PythonプロジェクトのanthropicパッケージをSDK 1.x系へ移行支援** — https://github.com/anthropics/claude-code/releases/tag/v2.1.239
  - **何が起きたか**: 同v2.1.239で、組み込みskill `claude-api`（8/19付ダイジェストで既報：コンテキストコストを200k超→約25kトークンに削減した機能）に `/claude-api upgrade` コマンドが追加され、Pythonプロジェクトの `anthropic` パッケージを0.x系から1.x系へ移行する作業を支援するようになった。Python向けリファレンスドキュメントも1.x系の変更に合わせて更新されている。
  - **なぜ注目されているか**: `anthropic` Python SDK 1.0では、レガシーのText Completions APIやMessages系メソッドの`temperature`/`top_p`/`top_k`旧パラメータが削除され、HTTP層も`httpx`から互換フォークの`httpx2`へ移行するなど、単純な書き換えでは済まない破壊的変更が複数入っている。手動移行が手間になる規模の変更だからこそ、専用の移行コマンドが用意された。
  - **使いどころ**: 個人開発のクイズアプリはNext.js/TypeScript中心のため今すぐは不要。ただし採点ロジックの検証スクリプトなどでPython＋`anthropic`パッケージを使う場面が今後出てきたら、`/claude-api upgrade`で移行の下調べをさせるとよい。
