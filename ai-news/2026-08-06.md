# 2026-08-06

- **[公式][実務] Claude Code v2.1.223 リリース——`/review` が `/code-review` のエイリアスに、Bash 権限バイパスを修正** — https://code.claude.com/docs/en/changelog
  - `/review` は `/code-review`（現在の diff や `/code-review <level> <pr#>` で PR をレビュー、`ultra` でクラウド深掘りレビュー）のエイリアスとなり、レベル未指定なら前回指定したレベルを再利用するようになった。タブや不可視 Unicode でコマンドの一部を承認ダイアログから隠す Bash 権限バイパスも修正。クラウドセッションには `claude --teleport <session id>` でローカル継続するヒントが追加された。
- **[公式][実務] Claude Opus 4.1（`claude-opus-4-1-20250805`）が本日 8/5 付で retired（Claude API 上）** — https://platform.claude.com/docs/en/about-claude/model-deprecations
  - 6/5 に告知されていた60日間の猶予期間が終了し、Claude API・Claude Platform on AWS・Microsoft Foundry 上でこのモデル ID へのリクエストは失敗するようになった。推奨移行先は `claude-opus-4-8`。CI や自動化スクリプトでモデル ID をハードコードしている場合は要確認。
- **[実務] 自前のレビュースキルをやめて、Claude Code の /code-review に乗り換えた（Zenn）** — https://zenn.dev/tmasuyama1114/articles/claude_code_code_review_guide
  - 自作していたレビュー用スキルを廃止し、公式の `/code-review` に一本化した実践記。指摘の重要度別表示など運用面の変化を具体的に紹介している。上記 v2.1.223 の `/review` エイリアス化とあわせて読むと、自前レビュー運用を見直す判断材料になる。
- **[実務] Claude Code × AWS MCP Server によるマルチアカウント操作（Qiita）** — https://qiita.com/eureka_/items/cf4b7690dab316cceb1d
  - AWS MCP Server で複数の AWS アカウントを1セッション内で切り替えるには、OAuth ではなく SigV4 認証を選ぶ必要があるという設定上の注意点を実機検証。AWS マルチアカウント運用をしているチームがハマりやすいポイントとして押さえておきたい。
