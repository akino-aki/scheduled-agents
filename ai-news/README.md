# ai-news

Claude Code を中心とした AI の最新情報。**毎日 7:12 (JST)** にクラウドエージェントが収集する。

`YYYY-MM-DD.md` が1日分。新しい情報が無い日は「該当なし」とだけ書かれる（件数を埋めない）。

## タグ

| タグ | 意味 |
|---|---|
| `公式` | Anthropic 公式の情報（リリースノート、ドキュメント、公式ブログ） |
| `実務` | 仕事で使えそうな技（コードレビュー、CI/CD、IaC、チーム導入、Skill、Hooks、MCP） |
| `企画` | 動画・記事のネタになりそうなもの |

ループエンジニアリング関連は [`../loop-engineering/`](../loop-engineering/) が別途扱う。
