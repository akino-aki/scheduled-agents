- **[公式][企画] Claude Code v2.1.290〜v2.1.292（10/5〜10/6）— 無人routine・スケジュールタスクの信頼性に関わる不具合をまとめて修正。会話compaction後やコンテナ再起動後のwakeup消失、`/resume`/`/branch`/`/clear`後に新規作成したタスクが発火しない問題など** — https://github.com/anthropics/claude-code/releases/tag/v2.1.292
  - **何が起きたか**: v2.1.290で「会話がcompactionされた後`/loop`やスケジュールタスクのwakeupが静かに復帰しない」「コンテナ再起動でcloud sessionの保留中wakeupが失われたまま眠り続ける」、v2.1.292で「`/resume`・`/branch`・`/clear`後に新規作成したスケジュールタスクが発火しない」「`/loop`実行中にプロセスが再起動すると保留中のwakeupが失われ静かに停止」が修正された。「routine runが完了後も数時間『running』表示のまま」という表示不整合も同時に修正。

  - **使いどころ**: 自作routine・`/loop`を日常的に使っているなら更新を優先する価値が高い。特に`/resume`や`/clear`の直後にスケジュールタスクを新規作成する運用をしているなら、これまで発火しなかった可能性がある。

- **[公式][実務] Claude Code v2.1.292（10/6）— Code ReviewがPRでCLAUDE.mdを編集した場合にその変更を無視していた不具合を修正、以後はベースブランチ側のCLAUDE.mdを使う仕様に** — https://github.com/anthropics/claude-code/releases/tag/v2.1.292

  - **なぜ注目されているか**: 9/30付の本ダイジェストで報告したissue #98133（REVIEW.mdをPRブランチ上で書き換えてもベースブランチ側の内容が適用され続ける、未修正）と同じ「PRブランチ上のレビュー設定ファイル編集が反映されない」パターン。CLAUDE.mdについては今回「ベースブランチ優先」が仕様として明文化され、同様の挙動が意図した設計である可能性が高いと見て取れる。

- **[公式][実務][企画] Claude Code v2.1.292（10/6）— AgentツールにサブエージェントのReasoning effortを指定する`effort`パラメータを追加** — https://github.com/anthropics/claude-code/releases/tag/v2.1.292
  - **何が起きたか**: リリースノートに「Added an `effort` parameter to the Agent tool, so Claude runs a sub-agent at the effort level you ask for」と明記された。呼び出し側がサブエージェントの思考の重さ（low〜max等）を指定できる。
  - **なぜ注目されているか**: 従来サブエージェントの思考の重さは呼び出し元が明示的に制御する手段が無かった。コストを意識したサブエージェント設計を公式にサポートする変更で、本ダイジェストを動かすこの環境のAgentツール自体にも既に同じ`effort`パラメータが実装済みであることが確認できる。
  - **使いどころ**: skill/hook/routineを自作してサブエージェントを多用しているなら、ファイル検索や定型確認など単純な作業には低いeffort、複雑な判断を伴うタスクには高いeffortを指定してコストを抑える設計に切り替える価値がある。クイズアプリの出題判定を複数エージェントに分担させる設計でも、難易度に応じてeffortを変える発想が使える。
